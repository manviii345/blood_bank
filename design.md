## Design Direction

The design should feel:

* Original
* Editorial
* Elegant
* Confident
* Modern but timeless
* Visually memorable without being flashy

Avoid:

* Repetitive card grids everywhere
* Excessive rounded corners
* Giant padding on every section
* Generic Inter/Poppins-only look
* Bland monochrome SaaS layouts
* Emoji-based decoration
* Copy-paste AI landing page structures
* Oversimplified hero sections with centered text + button + image

The website should look like it was crafted by an actual creative designer.

---

## Visual Style

### Typography

Use distinctive, tasteful font pairings.

Examples of direction:

* Space Grotesk + Source Serif
* General Sans + IBM Plex Serif
* Clash Display + Inter
* Satoshi + Instrument Serif
* Neue Montreal + Literata

Use typography hierarchy creatively:

* Large editorial headings
* Asymmetrical text blocks
* Mixed font weights
* Tight and loose spacing intentionally
* Strong visual rhythm

Avoid making everything the same font size and spacing.

---

## Color Palette

Use a refined, unique palette instead of default blue-purple gradients.

Possible directions:

* Warm ivory + charcoal + muted copper
* Deep forest + cream + pale sage
* Off-black + silver + soft lavender accents
* Stone gray + muted orange + antique white
* Midnight navy + faded gold + soft gray

The palette should feel curated and premium.

Avoid:

* Neon gradients everywhere
* Random bright colors
* Default Tailwind color combinations

---

## Layout & Composition

Break away from predictable AI layouts.

Use:

* Asymmetrical sections
* Layered compositions
* Mixed-width containers
* Intentional whitespace
* Editorial-inspired layouts
* Visual tension and balance
* Overlapping elements where appropriate
* Dynamic section transitions

Not every section should look boxed and centered.

Some sections can:

* Have split layouts
* Use staggered grids
* Use horizontal movement
* Include oversized typography
* Include subtle background textures or patterns

---

## Animations

Use subtle, premium animations only.

Examples:

* Smooth reveal on scroll
* Soft parallax movement
* Hover transitions with depth
* Elegant text motion
* Image masking animations
* Layer fade-ins
* Smooth page transitions

Avoid:

* Excessive bouncing
* Over-the-top motion
* Cheap glassmorphism effects
* Constant floating animations

Animations should feel cinematic and refined.

---

## Icons & Graphics

Do NOT use emojis.

Use:

* Minimal custom icon style
* Thin-line icons
* Duotone icons
* Abstract geometric accents
* Elegant SVG illustrations
* Artistic shapes or subtle grain textures

Icons should feel consistent and intentional.

---

## UI Quality

Every component should feel handcrafted.

Requirements:

* Beautiful spacing rhythm
* Clean alignment
* Responsive design
* Strong visual hierarchy
* Carefully chosen hover states
* Distinct section identities
* Custom buttons and inputs
* High-end interaction polish

The site should feel:

* Premium
* Creative
* Designer-made
* Modern without looking trendy-for-the-sake-of-trendy

---

## Frontend Expectations

Use:

* React / Next.js
* Tailwind CSS (customized heavily)
* Framer Motion for subtle animations
* Responsive mobile-first design
* Reusable but non-generic components

Do NOT generate boilerplate-looking Tailwind UI.

Customize:

* Border radius
* Shadows
* Grid systems
* Section spacing
* Typography scale
* Navigation behavior

---

## Final Goal

The final website should:

* Stand out visually
* Feel memorable
* Avoid looking AI-generated
* Feel like it belongs on Awwwards or a premium design showcase
* Prioritize design taste over trend spam

Think:
“Creative studio meets modern product design.”

The result should feel curated, artistic, and premium rather than generic SaaS.
