# Component Guide

*(This document will track reusable UI components and their usage)*

## Typography & Layout
- Page layouts with intentional whitespace
- Text hierarchy adhering to editorial styling

## Core Components
- `Button`: Custom buttons avoiding generic styles. Supports variants like `primary`, `secondary`, `outline`, `ghost`.
- `Card`: Custom layered containers for displaying content, without generic full borders/shadows.
- `Input`: Custom form fields.
- `Badge`: For status indicators (e.g., urgent, completed, expired).
